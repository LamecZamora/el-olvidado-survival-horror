# 🗺️ Mapa de Zonas - El Olvidado

## Descripción General

El juego consta de **6 zonas interconectadas** que Eddie debe recorrer para encontrar a sus padres y descubrir la verdad sobre PharmaCorp.

---

## 📍 Zona 1: El Barrio - Apartamento de Eddie

**"El comienzo del fin"**

| **Enemigos** | Ninguno (zona tutorial) |

| **Merchant** | Ninguno |

- **Apartamento de Eddie**: 40x40 studs
- **Habitaciones**: Sala, cocina, dormitorio, baño
- **Paredes**: Ladrillo marrón (139, 90, 43)

## 🚀 Cómo Usar el ZoneMapBuilder

### En Roblox Studio:

1. **Abrir Roblox Studio** con tu proyecto
2. **View → Script Editor**
3. **Copiar** el contenido de `ZoneMapBuilder.lua`
4. **Pegar** en el editor
5. **Presionar Play** (o F5)

### Resultado:
- Se crearán las 6 zonas en `Workspace → Zones`
- Cada zona tendrá:
  - Geometry (estructura básica)
  - SpawnPoints
  - Enemies (puntos de spawn)
  - Collectibles (posiciones marcadas)
  - Triggers
  - Merchants
  - Bosses (arenas)

### Después de ejecutar:
1. Revisar cada zona en el Explorer
2. Ajustar geometría según necesites
3. Agregar decoración detallada
4. Configurar scripts de enemigos
5. Implementar lógica de jefes

## 📝 Notas de Diseño

### Flujo de Juego
- **Zona 1**: Tutorial, sin combate
- **Zona 2**: Primer combate, primer merchant
- **Zona 3**: Introducción de enemigos blindados
- **Zona 4**: Máxima dificultad, todos los tipos
- **Zona 5**: Cambio de ritmo (abierto vs cerrado)
- **Zona 6**: Prueba final, todo junto

### Progresión de Dificultad
```
Z1: Tutorial → Z2: Fácil → Z3: Medio → Z4: Difícil → Z5: Medio-Alto → Z6: Muy Difícil
```

### Iluminación
- **Zonas tempranas**: Más brillantes, más seguras
- **Zonas tardías**: Oscuras, opresivas
- **ClockTime**: Varía de 7 (mañana) a 0 (noche profunda)
